Google Compute Engine

Read-only · First connector

Securely test access and inspect virtual machine instances in your configured Google Cloud project. This connector does not create, stop, delete, or modify resources.

Setup required

  1. In Google Cloud, create a dedicated service account and grant only the read-only permissions needed to view Compute Engine instances (for example, a suitable Compute Viewer role).
  2. Download its JSON key securely. Never paste the key into this page, a chat, or source code.
  3. In Cloudflare Pages → nova-engineering-universe → Settings → Variables and Secrets, add:
    • GCE_SERVICE_ACCOUNT_JSON — the full service-account JSON as a secret
    • GCE_PROJECT_ID — the Google Cloud project ID
  4. Enable the Compute Engine API in the Google Cloud project, then redeploy so the function receives the new variables.

Use a dedicated service account with least-privilege access. Keep its key private and rotate it if exposed. This initial connector is read-only.

Connector roadmap

The adapter pattern can be extended to services such as Google Cloud Storage, BigQuery, GitHub, databases, and internal engineering APIs. Each service needs its own authentication method, allowed actions, and permission checks; “any service” cannot be safely connected through one unrestricted URL/token field.
