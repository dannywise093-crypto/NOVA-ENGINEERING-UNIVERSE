CAD file exchange

Use this quick checklist when moving a model between tools. File exchange is a practical bridge; it is not a live synchronized connection to a running FreeCAD installation.

  1. In Cascade Studio, create your model and export .STEP when available for solid CAD, or .STL for mesh workflows.
  2. Save the downloaded file on your phone or computer.
  3. Open/import that file in FreeCAD on a supported desktop environment, then continue editing or checking it.
  4. Export a supported format from FreeCAD if you need to bring a model back into another CAD tool.

What is connected now?
