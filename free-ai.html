NOVA Local AI

An experimental AI assistant that runs inside your browser. No OpenAI, Grok, Claude, Gemini, Groq, or Pollinations API key is used by this page.

1. Choose a local model

The model is downloaded to your device/browser and can be large. WebGPU and enough memory are required; Android support varies.

2. Ask NOVA

Important limitations

This is a browser-local prototype, not a cloud-scale ChatGPT replacement. It does not automatically control FreeCAD, OpenCascade, or Cascade Studio yet. Model quality and speed depend on your device. The model runtime is loaded from a public CDN; after model files are cached, offline behavior depends on browser caching. No API key is requested by this page.
